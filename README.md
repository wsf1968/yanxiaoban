# 言小办 · Yanxiaoban

**开源个人语音助手 · 用说话的方式，处理日常事务。**

**状态：开源源码预览；项目主代码采用GPL-3.0-only，尚未提供正式发行安装包。**

言小办在Mac上运行，通过iPhone上的网页与Siri入口进行语音交互。模型理解需求、选择工具与条件，连接层调用接口、检查真实返回，并呈现结果和语音。默认针对DeepSeek优化；其他模型需逐项适配验证。

言小办的前身是“小派”项目的独立开源准备副本；本次只为开源项目定名，原自用版和原商用版仍保持各自名称。

这份副本来自商用产品代码。它不包含开发者的账号、个人历史、记忆、账本、设备授权或证书私钥，不读取开发者的现用服务配置。

## 功能与使用条件

- 语音对话、网页资料检索、旅游攻略、个人记忆与修改/遗忘。
- 高铁查询、京东/淘宝只读商品查询，需用户自己的账号及相应权限。
- 个人/家庭记账、通过Mac苹果系统事项连接的提醒和日程；家庭双手机使用仍需验收。
- 可选航班与参考票价接口默认关闭，启用后由用户直接向供应商支付调用费用；本轮未执行收费机票验证。不代预订，不保证最低价、含税总价或可购买性。
- 安装向导、本地HTTPS、手机授权、自检、备份与更新回退代码随源码提供。

当前构建路径面向Apple Silicon Mac，固定MLX运行环境要求macOS 26或更新版本；这不表示所有此类Mac或iPhone版本都已验证。Intel、Windows、Linux及安卓暂不列为首发支持。

日常使用需要Mac开机、已登录且不休眠，手机与电脑在同一Wi-Fi；模型与查询接口需要联网。历史与配置保存在本机，完成任务所需内容会发送给用户选择的在线服务，并非完全离线。

项目仓库：[wsf1968/yanxiaoban](https://github.com/wsf1968/yanxiaoban)。

## 开始使用

本目录是源码，不是双击即可使用的预编译安装包。开发者可按 [BUILDING.md](BUILDING.md) 准备依赖并构建安装助手。已确认免费自助使用、可选人工服务收费的原则；服务范围和售后说明见 [服务说明](docs/SERVICE_TERMS.md)，具体价格与订单信息在开放收费服务前另行明确。

编译后的预览安装助手默认使用独立数据目录 `~/Library/Application Support/言小办开源预览`。首次配置自己的模型账号，再按向导授权手机与相关功能。不要导入其他人的配置、证书、手机授权或历史。
