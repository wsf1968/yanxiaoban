# 查询供应商与费用

言小办提供接口连接代码；用户自行选择已支持的供应商、使用自己的账号和Key，按供应商规则支付调用费。项目不统一采购额度、不共享维护者账号、不代收供应商费用。使用其他平台需要相应适配器及验证，不能仅替换Key就宣称兼容。

当前代码的高铁接口对接聚合817，航班与参考票价接口对接聚合818；这不是对任意平台的通用兼容承诺。开源允许开发者增加其他适配器，业务理解、条件和候选选择仍由助手模型完成，连接层负责协议和返回值校验。

2026-11-03项目负责人的账号使用反馈：高铁每天10次免费查询；航班仅首次注册时提供3次试用额度，用完后付费，没有每日免费额度。额度、定价和资格由供应商管理，实际使用以用户自己的后台和最新规则为准，不构成言小办承诺。本轮没有消耗任何高铁或航班查询额度。

聚合航班默认不启用。需要时由用户准备可选地点资料、配置自己的账号并确认其计费责任；没有增加每次查询都反复确认的流程。地点资料如何本地获取见 [BUILDING](../BUILDING.md) 和 [素材说明](ASSETS.md)。数据附件的公开下载条件与查询接口的收费规则不同，也不代表可将供应商数据随GPL重新发布。

当前范围只有航班与参考票价查询，不代下单；税费、行李、舱位和可购买性未核验，不承诺最低价。离线协议测试与模拟结果不等于实时供应商或手机实测通过。
