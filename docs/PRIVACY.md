# 数据与远程协助说明

版本：1.0，2026-11-03。本说明覆盖言小办当前本地部署方案和已确认的服务原则；不替代各在线供应商的隐私政策，也不表示完成了独立隐私合规审计。

## 本地部署与在线调用

程序配置、账号凭证、会话、记忆和账本以保存在使用者Mac为交付方案。接口凭证用于向相应供应商认证；不能宣传为凭证从不离开电脑。完成任务所需的文本、上下文或工具内容会发送给用户选择的在线模型与接口，因此言小办不是完全离线产品。

当前默认路径在Mac本地处理语音识别和合成。改变供应商或部署方式时应重新说明实际数据流向，不据当前方案承诺所有替代方案都相同。

手机授权链接和二维码可授予访问权限，不应公开分享。用户可以管理授权设备。记忆遗忘与原始历史删除是不同操作；忘记一条偏好不等于历史、日志和备份中的相关内容全部永久擦除。

## 问题反馈

公开提交的问题、截图或附件会被他人看到。反馈只提供排查需要的信息，移除Key、账号凭证、授权链接、个人历史与账本。项目不要求用户为了普通问题反馈上传完整私人数据库。

## 人工服务

用户自己输入密码和Key，服务方不要求通过聊天发送这些凭证。远程访问应事先说明目的与范围，由用户同意后开始，用户可中止；只查看本次问题所需内容，结束后断开。

确需接收诊断材料或备份时，事先说明所需内容、用途、保存位置和期限，以及删除联系渠道。不得默认把客户材料用于公开案例、演示、训练或其他客户的服务。服务结束后清理不再需要的临时诊断副本和临时访问权限；有必要保留的订单或履约记录，应另行说明目的和期限。

实际服务主体、数据联系渠道、订单记录留存规则须在对外接单前补齐。未来若增加遥测、托管或其他数据收集，应先明确范围和告知方式，再评估是否需要另行同意，不能把本说明视为一揽子授权。
